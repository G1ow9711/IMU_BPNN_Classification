## 当前产品合同

- 右手腕佩戴。
- 一次训练会话只做一种主动作。
- 主动作确认后保持稳定；休息、静坐、低置信度和异类噪声不切换动作、不增加次数。
- 实体没有振动马达，固件和界面不得宣称振动反馈。
- 10 次动作的计数允许 ±2 次误差。
- 分类、计数、协议、硬件和 UI 的当前事实以源码、模型清单、自动化测试与真板验收为最终依据；历史章节只解释演进过程。

## 维护规则

- 算法修改只更新算法总文档，不再新增“某算法说明”“某轮校准”散文件。
- 协议或 TLV 修改只更新通信与存储文档。
- 硬件、驱动、手表 UI、亮度或低功耗修改只更新硬件与界面文档。
- 架构、状态机和任务流修改只更新系统架构文档。
- 测试结果、故障复盘和发布回退只更新测试运维文档。
- 新内容优先增加现有文档章节；只有出现全新、长期独立的产品域时才新增文件。
