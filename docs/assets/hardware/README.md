# 硬件图片资产

本目录保存项目维护者提供的硬件原图，用于说明 Waveshare ESP32-S3 智能手表从电路设计、PCB 布局、实物装配到产品界面的落地过程。仓库中的文件保持原始像素和编码，未做生成式修改。

## 图片说明

1. [`01_整板原理图.png`](01_整板原理图.png)：整板功能连接图，展示 USB、电源、ESP32-S3、AMOLED、触摸、QMI8658、RTC、音频和扩展接口之间的关系。图中存在 `Motor` 硬件接口，不表示当前产品安装或启用了振动马达。
2. [`02_PCB外形与器件布局.png`](02_PCB外形与器件布局.png)：PCB 外形、器件位号和接口位置图，用于定位元器件与装配关系；它不是电气连线原理图。
3. [`03_PCB与器件实物.jpg`](03_PCB与器件实物.jpg)：拆机实拍，可见 ESP32-S3 模组、QMI8658、电池、主板和表壳。
4. [`04_手表训练入口实拍.jpg`](04_手表训练入口实拍.jpg)：当前“ESP32 智慧运动助手”端侧界面实拍，展示电量、BLE 状态和训练入口。
